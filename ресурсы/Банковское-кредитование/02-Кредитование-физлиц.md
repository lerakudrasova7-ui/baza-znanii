# 02. Кредитование физических лиц

> Полный разбор розничных продуктов. По каждому: назначение, требования, плюсы/минусы, риски, документы, схема оформления, проверка клиента, причины отказов, досрочное погашение, реструктуризация, пролонгация, рефинансирование. Актуальность: 🔄 01.07.2026.

---

## 2.0. Общая правовая рамка розницы

- **353-ФЗ «О потребительском кредите (займе)»** — базовый закон для всех потребительских продуктов физлиц (кроме ипотеки в части, регулируемой 102-ФЗ). Устанавливает: раскрытие **ПСК**, форму договора (общие + индивидуальные условия), право на **отказ/досрочное погашение**, порядок уведомлений, ограничения неустоек.
- **102-ФЗ «Об ипотеке (залоге недвижимости)»** — для ипотеки.
- **230-ФЗ** — о защите прав при взыскании просроченной задолженности.
- **218-ФЗ** — кредитные истории, самозапрет.
- **115-ФЗ** — ПОД/ФТ (идентификация клиента).

### Общие для физлиц новеллы 2025–2026 🔄
- **Самозапрет на кредиты** (с 01.03.2025): гражданин через Госуслуги/МФЦ вносит в КИ запрет на выдачу ему кредитов/займов (полностью, только дистанционно, только МФО и т.д.). Банк **обязан проверять** самозапрет; выдача при активном запрете → долг не подлежит взысканию.
- **Период охлаждения по потребкредитам** (с 01.09.2025): деньги 50–200 т.р. доступны через **4 часа**, свыше 200 т.р. — через **48 часов** после подписания; до 50 т.р. и при созаёмщике/поручителе — не применяется. Механизм против мошеннических кредитов.
- **Постоянные кредитные каникулы** (348-ФЗ, с 01.01.2024) — см. раздел 2.13.

## 2.1. Потребительский кредит (кредит наличными)

**Назначение.** Нецелевой кредит на любые личные нужды: ремонт, лечение, покупки, крупные траты. Выдаётся деньгами (на счёт/карту), без отчёта о целях.

**Требования к заёмщику (типовые)** 🔄:
- гражданство РФ, возраст обычно 18–21 до 65–75 лет на дату погашения;
- регистрация в регионе присутствия банка;
- стаж на текущем месте от 3–6 мес., общий от 1 года;
- подтверждённый доход (для крупных сумм), приемлемый ПДН и КИ.

**Преимущества:** быстрое решение, деньги на любые цели, без залога, гибкая сумма/срок.
**Недостатки:** ставка выше, чем по целевым/обеспеченным; сумма ограничена доходом; переплата.
**Риски банка:** необеспеченность → высокий LGD; мошенничество; переоценка дохода клиента.
**Риски клиента:** перекредитованность, рост ПДН, штрафы за просрочку.

**Документы:** паспорт; для крупных сумм — подтверждение дохода (2-НДФЛ/справка по форме банка/выписка/данные ПФР через Госуслуги), СНИЛС, иногда второй документ.

**Схема оформления:**
```
Заявка (онлайн/офис) → идентификация → скоринг → (андеррайтинг) →
проверка самозапрета → решение → подписание → период охлаждения → выдача
```

**Особенности проверки клиента:** ПДН, КИ и рейтинг БКИ, стабильность дохода, антифрод (устройство, поведение), верификация работодателя.

**Причины отказов (типовые):** высокий ПДН, плохая КИ/просрочки, недостаточный/неподтверждённый доход, активный самозапрет, стоп-факторы СБ. Полный каталог — документ 07.

**Досрочное погашение:** право закреплено 353-ФЗ. Частичное/полное в любой момент; проценты пересчитываются за фактический срок пользования; уведомление банка (обычно за 30 дней или по условиям договора, для потребкредитов — упрощённо).

**Реструктуризация / каникулы / пролонгация / рефинансирование:** см. разделы 2.12–2.15.

## 2.2. Кредитная карта

**Назначение.** Возобновляемый кредитный лимит для повседневных трат с **льготным периодом (grace period)**, в течение которого проценты не начисляются при полном погашении.

**Ключевые параметры:**
- кредитный лимит (устанавливается по доходу/КИ);
- льготный период (часто 50–120 дней 🔄 у разных банков);
- минимальный платёж (обычно ~3–8% от долга + проценты);
- ставка на задолженность вне грейса; комиссия за снятие наличных (обычно выше и **без грейса**).

**Преимущества:** возобновляемость, грейс-период (фактически бесплатный краткосрочный кредит), кешбэк/бонусы, «подушка» на непредвиденное.
**Недостатки:** высокая ставка вне грейса, соблазн минимальных платежей → «долговая яма», грейс не распространяется на снятие наличных/переводы.
**Риски банка:** поведенческий риск, высокий уровень дефолтов в сегменте, фрод по картам.
**Риски клиента:** незаметный рост долга, лимит по карте увеличивает ПДН (учитывается даже неиспользованный лимит).

**Документы:** паспорт; доход — для крупных лимитов.

**Схема:** заявка → скоринг → выпуск карты с лимитом → активация → использование (транзакции) → выписка/минимальный платёж.

**Особенности проверки:** поведенческий скоринг для установления/повышения лимита; антифрод по операциям.

**Причины отказов:** те же, что по потребкредиту; плюс — уже высокая утилизация имеющихся карт.

**Досрочное погашение:** внесение сверх минимального платежа снижает долг; полное погашение в грейс — без процентов.

**Реструктуризация:** перевод долга по карте в кредит наличными с графиком (частая антикризисная мера), рефинансирование.

## 2.3. Ипотечный кредит

**Назначение.** Целевой долгосрочный кредит на покупку/строительство жилья под **залог недвижимости** (102-ФЗ). Приобретаемый объект (или иной) в залоге до полного погашения.

**Виды:** на новостройку (ДДУ, эскроу-счета), на вторичное жильё, на строительство дома (ИЖС), под залог имеющегося жилья, рефинансирование ипотеки, льготные госпрограммы.

**Требования** 🔄: возраст 18/21–65–75 на дату погашения; стаж; подтверждённый доход; **первоначальный взнос (ПВ)** обычно от 15–20%+; приемлемые ПДН/КИ; объект, прошедший проверку (юридическая чистота, оценка).

**Ключевые метрики:** **LTV** (кредит/стоимость залога), ПДН, срок (до 30 лет), ставка.

**Госпрограммы (примеры, детали меняются)** 🔄:
| Программа | Ставка | Условия (кратко) |
|-----------|--------|------------------|
| Семейная ипотека | до **6%** | семьи с ребёнком до 6 лет включительно / 2+ несовершеннолетних / ребёнок-инвалид. Лимит **12 млн** (Москва/СПб/области) и **6 млн** (иные регионы), ПВ от 20%. «Одна семья — одна льгота» с 01.02.2026; супруги — созаёмщики. С 01.07.2026 обсуждается дифференцированная ставка по числу детей/региону |
| IT-ипотека | льготная | для сотрудников аккредитованных IT-компаний (условия менялись) |
| Сельская, Дальневосточная, Арктическая | льготные | целевые территориальные программы |

> Массовая «льготная ипотека под 8%» завершена в середине 2024 г. Актуальные условия всех программ — на **ДОМ.РФ** и сайтах банков.

**Преимущества:** доступ к жилью без полной суммы; долгий срок → посильный платёж; льготные программы; налоговый вычет.
**Недостатки:** длительная долговая нагрузка, крупная переплата, обременение, обязательное страхование, риск при падении цен на жильё.
**Риски банка:** рыночный (падение цен → рост LTV), длинный процентный риск, дефолт заёмщика.
**Риски клиента:** потеря жилья при дефолте, валютный риск (для валютной ипотеки — исторически проблемный), рост платежа при плавающей ставке.

**Документы:** паспорт, СНИЛС, подтверждение дохода и занятости, документы по объекту (правоустанавливающие, выписка ЕГРН, оценка), согласие супруга, брачный договор (при наличии), для новостройки — ДДУ/договор с застройщиком.

**Схема оформления:**
```
Заявка → одобрение заёмщика → подбор объекта → проверка объекта (юр. + оценка) →
одобрение объекта → страхование → сделка (кредитный договор + договор залога/ипотеки) →
регистрация в Росреестре (обременение) → выдача (перечисление продавцу/эскроу)
```

**Особенности проверки:** двойной андеррайтинг — **заёмщика** и **объекта** (юридическая чистота, обременения, притязания, качество застройщика). Обязательное **страхование предмета залога**; страхование жизни/титула — добровольно, но влияет на ставку.

**Причины отказов:** высокий ПДН, недостаточный ПВ, проблемы с объектом (низкая ликвидность, юридические дефекты, «неипотечный» дом), плохая КИ, нехватка/неподтверждённость дохода.

**Досрочное погашение:** право по 102-ФЗ/353-ФЗ; частичное с уменьшением срока или платежа; полное — снятие обременения в Росреестре.

**Реструктуризация:** изменение срока/ставки, ипотечные **каникулы** (см. 2.13), рефинансирование (2.15).

## 2.4. Автокредит

**Назначение.** Целевой кредит на покупку авто (нового/с пробегом) под **залог этого автомобиля** (обычно ПТС в залоге, запись в реестре уведомлений о залоге движимого имущества).

**Виды:** классический автокредит, программы с господдержкой/от автопроизводителей (субсидированная ставка), кредит на авто с пробегом.

**Требования** 🔄: возраст, стаж, доход; ПВ (часто 0–20%); КАСКО (нередко обязательно на срок кредита); приемлемые ПДН/КИ.

**Преимущества:** ниже ставка, чем по наличным (есть залог); спецпрограммы производителей; быстрое оформление в автосалоне.
**Недостатки:** обязательное КАСКО удорожает; авто в залоге (нельзя свободно продать); быстрое падение стоимости залога.
**Риски банка:** высокая амортизация залога (LGD растёт), угон/тоталь (нивелируется КАСКО), мошенничество с авто.
**Риски клиента:** удорожание из-за страховки, обесценение авто быстрее погашения долга.

**Документы:** паспорт, ВУ, доход, договор купли-продажи/счёт от салона, ПТС/СТС.

**Схема:** заявка (часто в салоне) → скоринг → одобрение → оформление КАСКО → договор + залог → перечисление продавцу → регистрация залога в реестре.

**Особенности проверки:** проверка авто (не в залоге/розыске, VIN, реальность продавца), для б/у — оценка, история.

**Причины отказов:** ПДН/КИ; проблемное авто/продавец; отказ от обязательной страховки; для нецелевых под залог авто — МПЛ (см. 01).

**Досрочное погашение:** право по 353-ФЗ; после погашения — снятие залога.

**Реструктуризация/рефинансирование:** возможны; часто рефинансируют в потребкредит без залога после снижения долга.

## 2.5. POS-кредитование (кредит в точке продаж)

**Назначение.** Целевой кредит на конкретный товар/услугу прямо в магазине/онлайн-корзине (техника, мебель, обучение, медуслуги). Оформляется за минуты.

**Особенности:** часто «0-0-24» и рассрочки (проценты субсидирует продавец), маленькие суммы, экспресс-скоринг по минимуму документов (паспорт).

**Преимущества:** мгновенность, минимум документов, рассрочки без переплаты.
**Недостатки:** высокая ставка при обычном POS, навязанные страховки/допуслуги, импульсивность покупок.
**Риски банка:** высокий фрод и дефолтность, зависимость от партнёра-ретейлера.
**Риски клиента:** переплаты, множество мелких кредитов → рост ПДН.

**Документы:** обычно только паспорт (для малых сумм).
**Схема:** выбор товара → заявка у кассы/в корзине → экспресс-скоринг → одобрение → оплата товара банком продавцу.
**Причины отказов:** плохая КИ, высокий ПДН, срабатывание антифрода, лимит по экспресс-скорингу.

## 2.6. Образовательный кредит

**Назначение.** Оплата обучения. В РФ распространён **образовательный кредит с господдержкой** 🔄 (льготная ставка, субсидируемая государством; льготный период на время учёбы + отсрочка тела).

**Особенности:** пониженная ставка, отсрочка погашения основного долга на период обучения (+ несколько месяцев), оплата напрямую вузу.
**Преимущества:** доступ к образованию, низкая ставка, гибкий старт погашения.
**Недостатки:** ограничен аккредитованными вузами/программами; долг сохраняется при отчислении.
**Документы:** паспорт, договор с вузом, справка о стоимости обучения.
**Причины отказов:** несоответствие вуза/программы условиям, плохая КИ.

> Условия программы господдержки уточнять на официальных порталах (Минобрнауки, банки-участники).

## 2.7. Кредит под залог недвижимости (нецелевой)

**Назначение.** Крупный нецелевой кредит под залог имеющейся недвижимости (квартира, дом, коммерческое помещение). Деньги на любые цели.

**Преимущества:** большая сумма, ниже ставка (есть залог), длинный срок.
**Недостатки:** риск потери недвижимости, оценка/страхование/оформление залога, LTV обычно ≤ 60–70% стоимости.
**Риски банка:** ликвидность и юр. чистота объекта, снижение цен.
**Документы:** как по ипотеке + правоустанавливающие на закладываемый объект.
**Схема:** заявка → оценка объекта → андеррайтинг → договор + ипотека (регистрация обременения) → выдача.
**Причины отказов:** низкая ликвидность/дефекты объекта, высокий ПДН, проблемы с правами (доли, прописанные несовершеннолетние, обременения).

> ⚠️ Практический риск-фокус (важно для бизнеса «залоговое финансирование»): сделки «займ под залог единственного жилья» несут повышенный юридический и репутационный риск; критична **чистота сделки** и защита прав заёмщика.

---

## 2.8. Кредит под залог автомобиля (нецелевой, «автоломбардный»)

**Назначение.** Нецелевой кредит под залог имеющегося авто (ПТС остаётся у клиента, авто в пользовании; либо у МФО — с хранением).
**Преимущества:** быстро, без подтверждения цели, авто остаётся в пользовании.
**Недостатки:** высокая ставка (особенно у МФО), риск изъятия при дефолте, дисконт к стоимости.
**Риски банка:** амортизация и сокрытие/продажа предмета залога.
**Причины отказов:** старое/неликвидное авто, обременения, плохая КИ. Подпадает под **МПЛ по нецелевым под залог авто** (см. 01).

---

## 2.9. Кредит под поручительство

**Назначение.** Кредит, где возврат обеспечен **поручительством** третьего лица (ст. 361–367 ГК РФ). Поручитель отвечает солидарно (по общему правилу) при неисполнении заёмщиком.

**Когда применяется:** недостаточный доход/КИ заёмщика; крупные суммы; молодые заёмщики без истории; корпоративные поручители по кредитам ИП/МСП.
**Преимущества:** повышает одобряемость и/или сумму, может снизить ставку.
**Недостатки:** ответственность и рост ПДН у поручителя; риск для отношений; поручитель несёт полный риск заёмщика.
**Особенности проверки:** андеррайтинг **и заёмщика, и поручителя** (доход, ПДН, КИ поручителя).
**Причины отказов:** слабый поручитель (высокий ПДН/плохая КИ), формальное поручительство.

> Юридически: платёж по кредиту у поручителя учитывается в его ПДН; при дефолте у поручителя возникает право регресса к заёмщику.

---

## 2.10. Кредит без обеспечения (бланковый)

**Назначение.** Необеспеченный кредит только под платёжеспособность и репутацию заёмщика (большинство кредитов наличными и карт).
**Преимущества:** быстро, без залога/поручителей.
**Недостатки:** выше ставка, меньше сумма, жёстче требования к ПДН/КИ.
**Риски банка:** высокий LGD (нет обеспечения) → компенсируется ставкой и отбором.
**Причины отказов:** те же базовые (ПДН, КИ, доход, самозапрет, антифрод).

---

## 2.11. Рефинансирование

**Назначение.** Погашение действующего кредита (кредитов) за счёт нового — на лучших условиях (ниже ставка, меньше платёж, объединение нескольких кредитов в один).

**Виды:** внутреннее (в том же банке) и внешнее (в другом банке); рефинансирование ипотеки, потребкредитов, карт, автокредитов; **консолидация** нескольких долгов.

**Когда выгодно:** ставка снизилась существенно; остаток срока большой (для ипотеки — эффект больше в первой половине срока из-за аннуитета); нужно снизить платёж/объединить долги.

**Требования:** кредит без текущих просрочек (обычно), нормальные ПДН/КИ, «возраст» кредита от нескольких месяцев.
**Особенности:** при рефинансировании ипотеки — временный период повышенной ставки до перерегистрации залога на новый банк; проверка объекта повторно.
**Причины отказов:** просрочки, ухудшение дохода/КИ с момента первого кредита, высокий совокупный ПДН.
**Ошибка клиента:** гнаться за низкой ставкой, не считая расходов на переоформление (страховки, оценка, госпошлины) — реальная выгода может «съедаться».

---

## 2.12. Реструктуризация

**Определение.** Изменение условий действующего кредита из-за ухудшения платёжеспособности заёмщика (в отличие от рефинансирования — это работа с проблемным/предпроблемным долгом внутри того же договора/банка).

**Инструменты:** увеличение срока (↓ платёж), снижение ставки, отсрочка тела/процентов, изменение графика, объединение платежей, частичное списание неустоек.
**Когда:** временные трудности (потеря работы, снижение дохода, болезнь).
**Плюсы для банка:** избежать дефолта и дорогого взыскания, сохранить клиента, лучше резервирование, чем по «плохому» долгу.
**Минусы:** ухудшение категории качества, удлинение риска.
**Для клиента:** сохраняет КИ лучше, чем просрочка/дефолт (хотя факт реструктуризации отражается).

## 2.13. Кредитные каникулы 🔄

**Постоянный механизм** (348-ФЗ, с 01.01.2024; закреплён в 353-ФЗ, ст. 6.1-2) — право заёмщика-физлица на отсрочку платежей в трудной жизненной ситуации.

**Условия (кратко):**
- **Основания:** снижение дохода более чем на **30%** к среднему за прошлый год **или** нахождение в зоне ЧС/пострадавший от ЧС.
- **Срок отсрочки:** от 1 до **6 месяцев** (по выбору заёмщика).
- **Периодичность:** раз в 5 лет по одному договору (для договоров, заключённых не ранее 01.03.2024).
- **Лимиты суммы кредита** для права на каникулы 🔄: потребкредит без залога — **до 450 тыс. руб.**, автокредит — до 1,6 млн, ипотека — по отдельным (ипотечным) лимитам ДОМ.РФ/региона.
- Также действуют **ипотечные каникулы** (76-ФЗ) и специальные каникулы для отдельных категорий.
- С 01.10.2025 право на кредитные каникулы распространено на **самозанятых и МСП** (свои лимиты сумм).

**Важно для клиента:** каникулы отражаются в КИ, но это не просрочка; проценты за период начисляются по правилам закона.

---

## 2.14. Пролонгация

**Определение.** Продление срока договора (чаще для линий, овердрафтов, разовых кредитов юрлиц; в рознице — как форма реструктуризации). Оформляется допсоглашением. Для банка — переоценка риска на новый срок; для клиента — снижение платёжной нагрузки.

## Чек-лист менеджера по рознице
- [ ] Идентификация клиента (115-ФЗ), проверка **самозапрета**
- [ ] Расчёт **ПДН** со всеми обязательствами, попадание в **МПЛ**
- [ ] КИ и рейтинг БКИ, стабильность дохода
- [ ] Подбор продукта под цель и профиль клиента
- [ ] Для целевых — проверка объекта/товара/авто
- [ ] Для обеспеченных — оценка, LTV, страхование
- [ ] Раскрытие **ПСК**, объяснение грейса/графика
- [ ] Учёт **периода охлаждения** (сроки доступа к деньгам)
- [ ] Информирование о праве на досрочное погашение и каникулы

## Вопросы, которые задаёт менеджер клиенту
1. Цель кредита и желаемая сумма/срок?
2. Официальный и совокупный доход, форма подтверждения?
3. Действующие кредиты, карты, поручительства (для ПДН)?
4. Место работы, стаж, устойчивость дохода?
5. Наличие созаёмщика/поручителя/залога?
6. Были ли просрочки, реструктуризации, банкротство?
7. Оформлен ли самозапрет; согласие на запрос КИ?

## Типичные ошибки клиентов
1. Берут максимум, а не необходимое → перегруз ПДН.
2. Платят по карте только минимальный платёж.
3. Не читают ПСК и график, «ведутся» на низкую ставку без учёта страховок.
4. Гонятся за рефинансированием без расчёта реальной выгоды.
5. Скрывают долги — всё равно видно в КИ, но растёт риск отказа.

## Типичные ошибки менеджеров
1. Не проверяют самозапрет и совокупный ПДН.
2. Подбирают продукт «по плану продаж», а не под клиента.
3. Навязывают страховки без разъяснения права отказа.
4. Слабо проверяют объект/залог в целевых продуктах.

## Рекомендации
- Всегда считать источник погашения и «запас прочности» (стресс к платежу +20–30%).
- Для клиента с высоким ПДН — консолидация/рефинансирование вместо нового кредита.
- Обеспеченные продукты — при крупных суммах и длинных сроках.
