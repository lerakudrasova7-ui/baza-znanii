# 10. Практические кейсы

> Разбор ситуаций для тренировки суждения. Кейсы учебные (собирательные), иллюстрируют принципы из разделов 01–09. Цифры условны; актуальные нормы — 🔄 01.07.2026.

---

## 10.1. Хорошие заёмщики

### Кейс 1. «Идеальный розничный заёмщик»
- Женщина, 35 лет, врач в госклинике, стаж 8 лет, белый доход 90 т.р., подтверждён 2-НДФЛ и выпиской.
- Действующих кредитов нет, карта с лимитом 50 т.р., утилизация 10%. КИ чистая, рейтинг высокий.
- Запрос: кредит наличными 300 т.р. на 3 года.
- **Расчёт:** платёж ≈ 12–14 т.р.; ПДН ≈ (14 + минимальный по карте) / 90 ≈ 18%.
- **Решение:** одобрение по лучшей ставке. **Почему:** низкий ПДН, стабильная занятость, чистая КИ, «запас прочности» большой.

### Кейс 2. «Прозрачный МСП»
- ООО, оптовая торговля, 4 года на рынке, выручка растёт, обороты по счёту соответствуют отчётности.
- Долг/EBITDA = 2,1; ICR = 4; текущая ликвидность 1,8; картотеки/налоговых долгов нет.
- Диверсифицированные покупатели, собственник готов поручиться, есть ликвидная коммерческая недвижимость.
- Запрос: ВКЛ 20 млн на пополнение оборота.
- **Решение:** одобрение с обеспечением (залог недвижимости + поручительство бенефициара) и ковенантами. **Почему:** здоровый денежный поток, умеренная нагрузка, прозрачность, ликвидный залог.

## 10.2. Плохие заёмщики

### Кейс 3. «Перекредитованный оптимист»
- Мужчина, 40 лет, доход 70 т.р. (частично «серый»). Уже 3 кредита + 2 карты почти в ноль.
- Суммарные платежи ≈ 42 т.р. **ПДН ≈ 60%.** Есть просрочка 15 дней по карте.
- Запрос: ещё 200 т.р. наличными «закрыть дыры».
- **Решение:** отказ. **Почему:** высокий ПДН (МПЛ + надбавки), свежая просрочка, признаки «кредитной спирали».
- **Что посоветовать:** не новый кредит, а **консолидация/рефинансирование** существующих долгов и снижение ПДН; закрыть неиспользуемые карты.

### Кейс 4. «Красивая отчётность, пустой счёт»
- ООО показывает прибыль в отчётности, но обороты по счетам близки к нулю, зарплата платится «в конверте», НДС минимальный.
- Признаки: несоответствие оборотов выручке, массовый адрес, недавняя смена директора.
- **Решение:** отказ. **Почему:** нет реального денежного потока (источника погашения), риск «технической» компании, 115-ФЗ.

## 10.3. Сложные (пограничные) кейсы

### Кейс 5. «Хороший бизнес, слабый залог»
- ИП, стабильный денежный поток, Долг/EBITDA = 3, но из обеспечения — только узкоспециальное оборудование (низкая ликвидность).
- **Проблема:** платёжеспособность ок, обеспечение слабое (высокий LGD).
- **Структурирование:** снизить необеспеченную часть; добавить **зонтичное поручительство Корпорации МСП** (до 50%) и личное поручительство ИП; сократить срок; ковенанты по оборотам на счёт в банке.
- **Итог:** одобрение с комбинированным обеспечением. **Урок:** обеспечение — «план Б», но при слабом залоге усиливаем гарантиями/поручительствами и контролем потока.

### Кейс 6. «Сезонный бизнес»
- Фермерское хозяйство: выручка сконцентрирована осенью, весной — расходы на посевную.
- **Проблема:** равномерный аннуитет разрушит кассу весной.
- **Структурирование:** сезонный график (тело гасится после сбора урожая), грейс на инвестфазу, лимит под сезон; рассмотреть льготные программы Минсельхоза.
- **Урок:** график должен повторять денежный цикл клиента.

### Кейс 7. «Молодой заёмщик без истории»
- Клиент 22 года, доход 60 т.р. официально, стаж 8 мес., КИ пустая.
- **Проблема:** нет доказанной дисциплины, малый стаж.
- **Решение:** одобрить малую сумму/карту с небольшим лимитом ИЛИ с созаёмщиком/поручителем (родитель).
- **Урок:** пустая КИ — не «плюс»; начинать с малого продукта для наработки истории.

## 10.4. Ошибки клиентов (разбор)

| Ошибка | Последствие | Как правильно |
|--------|-------------|---------------|
| Веерная подача заявок в 10 банков за день | Всплеск запросов в КИ → снижение рейтинга, отказы | Подобрать 1–2 банка, пауза между заявками |
| Платить по карте только минимум | Долг почти не гасится, растёт переплата | Гасить в грейс или существенно выше минимума |
| Скрыть действующие долги | Всё видно в КИ; растёт недоверие → отказ | Быть честным, планировать ПДН |
| Взять максимум «с запасом» | Перегруз ПДН, риск просрочки | Брать необходимое, оставлять «подушку» |
| Игнорировать активный самозапрет | Автоматический отказ | Снять самозапрет заранее (учесть срок вступления) |
| Погнаться за низкой ставкой рефинансирования без расчёта | Расходы на переоформление «съедают» выгоду | Считать полную выгоду с учётом страховок/пошлин |

## 10.5. Ошибки менеджеров (разбор)

| Ошибка | Последствие | Как правильно |
|--------|-------------|---------------|
| «Протолкнуть» слабую заявку ради плана | Дефолт, потери, плохой портфель | Быть фильтром риска |
| Не проверить самозапрет/антифрод | Мошеннический кредит, невозвратный долг | Обязательные проверки на входе |
| Считать ПДН без карт/поручительств | Недооценка нагрузки, просрочки | Учитывать все обязательства |
| Оценить залог по рынку без дисконта | Недостаток при реализации | Консервативные дисконты, стресс цены |
| Не зарегистрировать залог движимого имущества | Потеря приоритета перед другими кредиторами | Регистрация в реестре уведомлений |
| Не раскрыть ПСК/условия | Жалобы, отказ на этапе охлаждения, правовой риск | Полное прозрачное информирование |

## 10.6. Реальные (типовые) причины отказов — быстрый разбор

- «Отказ без причины» у физлица чаще всего = высокий ПДН **или** свежая просрочка **или** сработавший антифрод.
- У бизнеса «внезапный отказ» = картотека/блокировка счёта, метки недостоверности в ЕГРЮЛ, несоответствие оборотов выручке.
- Полный каталог с шансами исправления — [[07-Причины-отказов]].

## 10.7. Схемы структурирования сделок (приёмы)

1. **Комбинированное обеспечение:** ликвидный залог + поручительство бенефициаров + (для МСП) зонтичное поручительство/РГО — когда одного залога мало.
2. **Сезонный/ступенчатый график:** синхронизация платежей с денежным циклом (сезонность, инвестфаза + грейс).
3. **Транширование (кредитная линия):** выдача под фактическую потребность → экономия процентов, контроль целевого использования.
4. **Уступка выручки (для контрактного кредитования):** перевод выручки по контракту на счёт в банке-кредиторе как источник погашения и контроль.
5. **Консолидация долгов (для физлица с высоким ПДН):** объединение нескольких кредитов/карт в один с меньшим платежом вместо нового кредита.
6. **Ковенанты вместо избыточного залога:** финансовые (Долг/EBITDA не выше X, поддержание оборотов) и нефинансовые (согласование новых займов) обязательства.
7. **Снижение LTV / рост ПВ:** при слабом залоге/высоком риске — уменьшить сумму или увеличить первоначальный взнос.
8. **Госпрограммы:** для МСП — «1764»; для семей — семейная ипотека; снижают ставку и повышают проходимость.

## 10.8. Мини-задачи для самопроверки

1. Клиент: доход 100 т.р., платежи по кредитам 35 т.р., карта с лимитом 100 т.р. (используется 80 т.р., минимальный платёж ~5 т.р.). Оцените ПДН и решение по новому кредиту с платежом 20 т.р.
   *Подсказка: ПДН ≈ (35 + 5 + 20)/100 = 60% → высокий, вероятен отказ/условия; сначала снизить нагрузку.*
2. Бизнес: Долг/EBITDA = 5, ICR = 1,3, обороты падают. Ваши действия?
   *Подсказка: высокая нагрузка + слабое покрытие процентов + отрицательная динамика → отказ или только под сильное обеспечение и сокращение суммы.*
3. Залог: узкоспециальное оборудование, оценка 10 млн. Какой LTV разумен?
   *Подсказка: низкая ликвидность → большой дисконт (40–60%), LTV ≤ 30–50%, т.е. кредит ≈ 3–5 млн, плюс поручительство.*

## Рекомендации
- Тренировать «главный вопрос»: **откуда вернутся деньги** (источник погашения), затем — что делать при дефолте (обеспечение).
- Всегда прогонять сделку через стресс (падение дохода/выручки, рост ставки, падение цены залога).
