## Правила работы с базой (важно)

### Приоритет достоверности источников
1. **Банк России** (cbr.ru) — нормативные акты, положения, указания, разъяснения.
2. **Федеральное законодательство** РФ (ГК РФ, профильные ФЗ).
3. **Официальные документы банков** (тарифы, условия, оферты).
4. **Государственные источники** (Минфин, Минэк, ФНС, ДОМ.РФ, Корпорация МСП).
5. **Профессиональные публикации** (аналитика, БКИ, отраслевые СМИ).
6. **Учебные материалы** (учебники, курсы, программы вузов).
7. **Практика рыночных специалистов** (брокеры) — только для понимания практики, с проверкой по официальным источникам.

### Дисциплина актуальности
- Всё, что меняется во времени (ставки, нормативы, лимиты, госпрограммы, требования банков), помечено значком 🔄 и датой проверки.
- Числовые значения проверены на **01.07.2026**. Перед использованием в работе — **перепроверять по первоисточнику** (cbr.ru, сайт банка, официальный портал программы).
- При противоречии источников база указывает приоритетный (обычно Банк России / закон) и объясняет расхождение.

## Дисклеймер
Материал носит учебно-методический характер и не является юридической, инвестиционной или банковской консультацией. Конкретные условия сделок определяются внутренними регламентами банка и действующими редакциями НПА на дату сделки.
