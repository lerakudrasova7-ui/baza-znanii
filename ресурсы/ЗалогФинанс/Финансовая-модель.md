# Финансовая модель платформы «ЗалогФинанс»

> ⚠️ Все цифры — смоделированные допущения на основе платформы и рыночных бенчмарков, не гарантия. Налоговые ставки (2025) сверить с бухгалтером.

Платформа прямого залогового финансирования P2P: соединяет частных инвесторов и заёмщиков. Каждая сделка проходит ИИ-проверку, юрпроверку, проверку залога и скоринг.

## 1. Бизнес-модель

Регулируемая инвестиционная платформа (ФЗ-259), маркетплейс P2P-залогового кредитования. Платформа **не несёт кредитный риск** (деньги инвестора → заёмщику через номинальный счёт), зарабатывает на трафике, скоринге, инфраструктуре и доверии. **Asset-light** — тело займа не на балансе, маржинальность кратно выше банка.

```
Заёмщик → заявка → [ИИ + юрпроверка + оценка залога + скоринг]
        → одобрение → документы → маркетплейс
Инвестор → аукцион ставок → финансирование → номин. счёт → выдача
        → (дефолт) → внесудебное взыскание 60 дней
Доход: комиссия заёмщика + комиссия инвестора + доп.услуги
```

## 16. Итоговый вердикт

### Жизнеспособность: **7,5 / 10**

Сильная unit-экономика (маржа 85%), asset-light, реальный залог, регуляторное окно, уникальное взыскание. Минус — зависимость от ликвидности инвесторов и рег. риска.

### 🔴 5 факторов провала
1. Дефицит инвесторского капитала (нет предложения денег).
2. Сбои во взыскании (60-дневная реализация не работает на практике).
3. Регуляторика ЦБ (ужесточение / отзыв из реестра).
4. Мошенничество (фиктивные залоги, сговор).
5. CAC > LTV — не дойти до BE (215 млн/мес) до конца денег.

### 🟢 5 факторов лидерства
1. Взыскание за 60 дней — ров против EstateGuru/Groundfloor.
2. Институциональный капитал (банки/фонды как якорные инвесторы).
3. Агентская сеть — дешёвое масштабирование origination.
4. Данные + ИИ-андеррайтинг — ниже дефолты → выше доходность → приток инвесторов.
5. Вторичный рынок + buyback-фонд — ликвидность и доверие ритейла.
