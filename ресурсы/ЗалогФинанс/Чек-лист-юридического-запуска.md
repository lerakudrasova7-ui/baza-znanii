# Чек-лист юридического запуска «ЗалогФинанс»

> ⚠️ Ориентир, не юридическое заключение. Критический путь (ООО → реестр ЦБ → правила платформы) обязательно вести с **корпоративным/fintech-юристом**.

**Форма:** ООО (хозяйственное общество). ИП нельзя — ФЗ-259. Позже при крупных раундах → АО.
**Критический путь:** Этап 1 → 3 → 4 (реестр ЦБ). Без записи в реестре операторов инвестплатформ работать нельзя.

---

## Этап 1. Регистрация ООО

- [ ] Название (полное + сокращённое)
- [ ] Юридический адрес (собственный / аренда / адрес учредителя)
- [ ] Учредители и распределение долей
- [ ] Уставный капитал (мин. 10 000 ₽; но для платформы нужны **собственные средства ≥ 5 млн ₽** — см. Этап 3)
- [ ] Директор (ген. директор)
- [ ] Устав
- [ ] Коды ОКВЭД (Этап 2)
- [ ] Подача в ФНС (онлайн через Госуслуги/банк, или у нотариуса)
- [ ] Открытие расчётного счёта
- [ ] Система налогообложения: **ОСНО** (финдеятельность ограничивает УСН)
- [ ] Печать, КЭП юрлица

## Этап 2. ОКВЭД (уточнить с юристом)

- [ ] 64.99 — предоставление прочих финансовых услуг
- [ ] 66.19 — вспомогательная деятельность в сфере финансовых услуг
- [ ] 64.92 — предоставление займов
- [ ] 62.01 — разработка ПО (для IT-аккредитации)

## Этап 3. Собственные средства

- [ ] Обеспечить **собственные средства ≥ 5 млн ₽** (требование ЦБ к оператору)
- [ ] Подтверждающие документы (баланс, при необходимости аудит)

## Этап 4. Включение в реестр операторов инвестплатформ ЦБ РФ ⭐

- [ ] **Правила инвестиционной платформы** (ключевой документ)
- [ ] Соответствие требованиям к органам управления (деловая репутация, квалификация, отсутствие судимости)
- [ ] Внутренние документы: управление рисками, хранение информации, раскрытие
- [ ] Сайт с обязательным раскрытием информации
- [ ] Заявление + пакет документов в Банк России
- [ ] Прохождение проверки и **внесение в реестр**

## Этап 5. ПОД/ФТ — ФЗ-115 (антиотмывание)

- [ ] Правила внутреннего контроля (ПВК)
- [ ] Назначить ответственное должностное лицо (СДЛ)
- [ ] Постановка на учёт в Росфинмониторинге
- [ ] Процедуры идентификации клиентов (KYC) и проверка по перечням

## Этап 6. Персональные данные — ФЗ-152

- [ ] Уведомление в Роскомнадзор (оператор ПДн)
- [ ] Политика обработки ПДн на сайте
- [ ] Формы согласий на обработку ПДн
- [ ] **Локализация данных на серверах в РФ** (см. хостинг — Yandex Cloud)
- [ ] Меры защиты (организационные + технические)

## Этап 7. Кредитные истории — ФЗ-218

- [ ] Договоры с БКИ (НБКИ / ОКБ)
- [ ] Согласия субъектов на запрос КИ ✅ *(уже встроено в продукт)*

## Этап 8. Договорная база

- [ ] Правила платформы / оферта
- [ ] Пользовательское соглашение
- [ ] Договор займа (инвестор ↔ заёмщик)
- [ ] Договор залога (ипотеки / залога движимого имущества)
- [ ] Агентский договор ✅ *(логика готова в продукте)*
- [ ] Согласия (ПДн, КИ) + политики (cookies)
- [ ] **Нотариальная оговорка** в договорах — для исполнительной надписи (внесудебное взыскание)

## Этап 9. Оформление залога

- [ ] Недвижимость → регистрация ипотеки/залога в **Росреестре**
- [ ] Авто/движимое → уведомление о залоге в реестре **ФНП** (через нотариуса)

## Этап 10. Банк-партнёр / номинальный счёт

- [ ] Договор с банком на **номинальный счёт** (сегрегация средств клиентов)
- [ ] Платёжная инфраструктура (эквайринг + выплаты)

## Этап 11. Сопутствующее

- [ ] **Товарный знак** «ЗалогФинанс» в Роспатенте (защита бренда)
- [ ] **IT-аккредитация** в Минцифры (налог 5% + страховые 7,6%)
- [ ] Электронные подписи: КЭП (юрлицо) + ПЭП/УНЭП (клиенты, подписание договоров)

## Минимальная последовательность до старта

1. ООО (Этап 1–2) — недели
2. Собственные средства 5 млн (Этап 3)
3. Пакет в ЦБ + правила платформы (Этап 4) — **самый долгий**, месяцы
4. Параллельно: ФЗ-115, ФЗ-152, договорная база (Этапы 5–8)
5. Банк-партнёр + оформление залога (Этапы 9–10)
6. Запуск

> Параллельно с юр-треком идёт технический трек (миграции ✅, S3 ✅, платежи, KYC, переезд на РФ-хостинг).
